# 开发交接记录

最后更新：2026-08-31

## 当前可用能力

- 官方教材目录加载：读取官方目录索引，支持学段、学科、年级、册次、版本筛选和多关键词检索。
- 资源展示：按“分类（学段、学科、年级、册次、版本）”聚合；单资源直接展示，多资源显示父子行；原始官方标题可见且可检索。
- 选择逻辑：父级全选和半选、全选当前结果、跳过已下载；跳过不阻止用户手动重下已下载资源。
- 登录：使用应用私有 Electron session；站内登录窗口；成功后自动关闭；支持退出并清除私有登录档案。
- 单项下载：解析教材详情并下载 PDF，写入 `Downloads/SmartEdu Textbook Library`；使用 `.part` 临时文件、PDF 文件头与目录大小校验、完成后原子改名。
- 下载反馈：未登录时立即在行内提示；已登录后显示解析、百分比下载、校验和完成/失败状态；成功后更新当前界面的已下载状态。
- 批量下载队列：把勾选资源建立顺序队列逐个下载；界面显示总进度、当前项、成功/失败/取消数量，任务页列出每项状态与失败原因。
- 暂停/继续/取消：暂停保留 `.part` 并支持 HTTP Range 断点续传；继续从断点续传；取消会清理未完成任务及其 `.part`。
- 失败重试与错误摘要：批次结束后可对失败或已取消的单项单独重试，错误原因逐项展示。
- 状态持久化：任务队列与已下载文件记录写入应用私有数据目录（开发期为 `.electron-data`）；重启后任务页保留可恢复任务，“已下载”标记仍可参与筛选与跳过。
- 孤立文件清理：启动时删除不属于任何已知任务的 `.part` 文件，避免临时文件无提示累积。
- 本地资料页：展示已下载文件索引，支持关键词搜索、学科筛选、打开文件、打开所在文件夹；文件被移动或删除时给出“文件已不在原位置”提示。
- 下载任务页增强：保留最近 5 个已完成/已取消批次的历史；支持“重试全部失败项”；运行项展示速度、已用时间和剩余时间，暂停项展示断点进度。
- Windows 分发：`npm run dist` 可生成 NSIS 安装版与便携版 exe；产物在 `release/`。当前使用默认 Electron 图标、未做代码签名，正式发布前需补图标、签名与 Windows 发布者配置。
- 自动化测试：Vitest 覆盖目录字段标准化、多关键词匹配/分类聚合/选择逻辑、文件命名与 PDF 校验、下载队列状态机（顺序下载、失败重试、暂停/继续、取消、重启恢复、孤立 `.part` 清理、历史归档、重试自动恢复暂停剩余项）；运行 `npm test`，当前 27 项通过。
- 开源仓库：源码已发布到 `https://github.com/run4u/smartedu-textbook-library`，采用 Apache-2.0；社区文件与 GitHub Actions CI 已启用，Ubuntu CI 通过。

## 已确认产品约束

- 保留原有稳定下载工具，不在其目录中修改功能。
- `contentId` 是资源身份；不得按标题防重、自动合并或自动跳过。
- 同一分类下的不同资源年度、大小或内容均需可见、可选择和可重复下载。
- 原始官方教材标题必须展示并参与搜索。
- 登录不得索取、记录或提交用户凭据、Cookie、Token、签名下载地址或教材文件到仓库。
- 用户偏好紧凑的单版本展示；多版本/多资源为辅助层级。

## 启动与排障

- 开发入口：仓库根目录的 `启动桌面端.cmd`，或在该目录执行 `npm run dev`。
- 启动后保持命令行窗口打开；关闭它会退出桌面程序。
- Electron 私有运行数据在开发期位于 `.electron-data`，已由 Vite 忽略，避免 Windows 文件锁使服务退出。
- 前端改动可热更新；修改 `electron/main.cjs`、`electron/preload.cjs` 或 `electron/download.cjs` 后必须完整重启。
