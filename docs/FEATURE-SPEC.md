# 功能规格与已确认决策

本文件记录产品层面的已确认决策。实现状态以 [开发交接记录](DEVELOPMENT-STATUS.md) 为准。

## 教材目录

- 使用官方目录数据，不以手工样例作为桌面端的实际数据源。
- 筛选项：学段、学科、年级、册次、版本；选项随其他已选条件动态收窄。
- 搜索支持空格分隔的多关键词，所有关键词同时匹配；搜索范围包括原始标题和分类字段。
- 原始官方标题必须完整保留，并以悬停提示补足被截断的文本。
- 筛选重置、搜索清除和各下拉选项必须可操作。

## 资源区分与列表

- 聚合键为：学段、学科、年级、册次、版本。标题不参与聚合键。
- 单资源分类作为紧凑单行显示；多资源分类使用父行加子行，子行直接可见。
- 父级复选框选中全部可选子项；部分选中时显示半选状态。
- 表格应保留：分类、原始教材名称、资源年度、文件大小、更新时间、短资源 ID、本地状态和下载操作。
- 分类、标题等可能截断的字段提供完整内容悬停提示。
- 左侧导航可收起，主列表中的分类与标题列可以弹性扩展。

## 选择与重复下载

- “全选当前结果”只影响当前筛选/搜索结果，并与“跳过已下载”状态一致。
- “跳过已下载”仅影响批量选择：启用时移除已下载项的自动选中；用户仍可手动勾选并重新下载它们。
- 已下载状态不得置灰成不可操作，不得禁止再次下载。
- 不做按标题、版本名或文件名的粗暴防重复下载。不同 `contentId` 的资源始终可下载。

## 文件命名与校验

- 新文件名包含分类、资源年度和短资源 ID，避免同名资源退化为 `(2)`、`(3)`。
- 文件写入完成前使用 `.part` 临时文件。
- 完成前校验 PDF 文件头和目录提供的文件大小；通过后原子改名。
- 后续批量任务必须定义中断时 `.part` 的恢复、继续或清理策略，不能让临时文件无提示累积。

## 登录与下载反馈

- 登录在 Electron 应用内完成，不借用用户默认浏览器，不索取用户账号、密码或 Cookie。
- 登录成功后登录窗口自动关闭；主界面展示已保存登录档案状态并可退出登录。
- 登录状态只是本地档案存在性提示，下载时仍以平台实际授权结果为准。
- 未登录点击下载应立即提示，不等待平台请求超时。
- 下载任务必须在界面内显示解析、传输进度、校验、完成与失败原因；不得只依赖延迟弹窗。

## 后续功能

- 批量下载（已实现，见开发交接记录）：顺序队列、总进度、暂停、继续、取消、失败重试和错误摘要。
- 本地资料库（已实现，见开发交接记录）：下载记录与文件路径本地持久化，本地资料页支持索引、关键词/学科筛选、打开文件和打开所在文件夹。
- 下载任务页（基础版已实现）：运行中、已完成、失败和可恢复任务。
- 目录快照：将缓存目录与新刷新目录对比，提示新增或变化的资源。变化标记需在用户明确查看或确认后才消失，不能因再次刷新自动抹除。
- 不将“同版但不同册次”“旧年度但仍可访问”等资源视为无价值重复项。

## 明确搁置

- 基于目录快照的更新提示具体交互尚未最终确定，暂不实现为自动静默刷新。
- 不进行按标题的自动合并、去重或跳过。
