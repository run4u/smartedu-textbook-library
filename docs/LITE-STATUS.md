## 本轮优化

1. 授权等待从该 PDF 地址首次出现计时，切换候选后重新计时，避免慢加载跳过授权等待。
2. 探针注入所有 frame，读取同源阅读器的请求和嵌入资源，跨域请求由原生钩子观察。
3. 按地址记录 fetch/Request 和并发 XHR 授权，不误用其他接口的授权头；限制采集内存。
4. 显示详情窗口时同步更新任务提示，表明等待登录或阅读确认。
5. 错误仅显示下载站点，不将完整签名地址写入界面和队列文件。
6. CI 包设置页显示短提交号，附件带构建信息与 SHA-256，保留配置改为 90 天。

验证：41 项 Vitest 通过，含 6 项直接执行 Lite 探针脚本的回归；TypeScript、前端构建和 Rust 格式检查通过。新增 Rust 等待状态和诊断脱敏回归仍需 Windows CI，本机缺少 MSVC `link.exe`。真实账号故障尚不能标记为解决。
