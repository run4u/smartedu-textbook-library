# 项目总体设计

## 项目定位

SmartEdu Textbook Library 是一款本地优先的 Windows 桌面应用，用于查找、比较、下载和管理用户通过本人账号可访问的教材资源。

它不是资源镜像站、爬虫服务或共享下载工具。应用只在用户本机运行，使用用户在应用内完成的平台登录；教材默认保存到系统“下载”目录下的 `SmartEdu Textbook Library` 文件夹，用户也可以在设置页选择其他本地目录。

## 要解决的问题

官方目录会同时保留不同年度、不同修订版本或内容不同但标题相同的教材。用户需要能够：

- 用学段、学科、年级、册次、版本和原始标题快速定位资源；
- 看清相近资源之间的年度、更新时间、文件大小和资源身份差异；
- 主动决定下载哪些资源，而不是被标题相同的“去重”逻辑替用户做判断；
- 在大文件或网络不稳定时了解下载进度、失败原因和任务状态；
- 在重启后仍能追踪本地文件和未完成任务。

## 目标用户

- 需要整理多个年级、版本或年度教材的教师、教研人员与学校管理人员；
- 需要建立个人离线教材库、且有权访问相应资源的用户；
- 需要比较同名教材不同资源版本的用户。

## 产品原则

### 资源优先，不按标题去重

`contentId` 是资源唯一身份。标题仅用于展示和检索，绝不能作为自动跳过、覆盖或合并的条件。同一分类下的不同资源必须全部保留为可见、可选、可下载的独立条目。

### 单资源高效，多资源可理解

绝大多数分类只有一个资源，应以紧凑单行展示。多个资源共享同一分类时才展示父子关系，父级支持全选和半选；用户无需先进入详情页才能看见子资源。

### 本地优先，状态可追溯

目录缓存、下载任务、文件映射和用户设置存储在本机。任何“已下载”状态仅作信息和筛选用途，不能阻止用户重新下载同一资源。

### 下载过程必须可见

点击下载后立即显示状态；至少包含登录/详情解析、传输进度、校验、完成或失败。错误信息应说明下一步操作，例如登录失效、资源无权限、网络失败或文件校验失败。

### 隐私与最小权限

登录仅在应用内的受限平台窗口中完成。Cookie、Token、签名地址、授权请求头、教材文件和完整网络日志都不得进入仓库、发布包或遥测数据。渲染界面不直接接触这些信息。

## 范围边界

本项目会提供：目录浏览、筛选搜索、用户授权会话、文件下载、校验、本地任务和资料库管理。

本项目不会提供：账号注册、账号共享、绕过登录或权限、集中式教材托管、公共下载链接、按标题自动删除资源，或将用户凭据上传至第三方服务。

## 目标架构

```text
Electron desktop shell
  -> React renderer: catalog, tasks, local library
  -> preload boundary: narrow typed IPC only
  -> main process services
       -> official catalog adapter
       -> private platform session adapter
       -> download queue and validation worker
       -> local metadata repository
       -> filesystem library
```

- `renderer`：只负责交互和展示，不访问 Node.js、Cookie 或平台授权数据。
- `preload`：提供最小 IPC 接口，并传递经过筛选的任务进度与错误信息。
- `main`：管理窗口、私有 session、目录同步、下载队列、文件写入和本地元数据。
- `repository`：后续使用 SQLite 保存目录快照、下载任务和文件映射；不保存明文授权信息。

## 交付路线

1. **可用下载闭环**：真实目录、筛选、登录、单项下载、进度、文件校验。
2. **任务与资料库**：批量队列、暂停/继续/取消、失败重试、`.part` 恢复、持久化已下载状态和本地资料视图。
3. **可靠发布**：自动化测试、Windows 安装包/便携版、升级策略、隐私审查和可复现构建。
4. **增强能力**：目录变化提示、可选 PDF 书签处理和更完善的本地搜索。任何增强均不得改变资源身份与用户选择权。

## 开源准备要求

- 发布前选择并写明许可证、贡献指南、行为准则和安全问题反馈渠道。
- 确保 Git 历史、示例数据、截图和发行产物不含真实账号信息、私有 session、教材文件或授权链接。
- 提供可复现的开发启动、测试和打包说明。
- 将平台相关实现隔离，便于在平台规则变化时独立维护或禁用相关适配器。
