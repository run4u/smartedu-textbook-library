# 测试基线

## 已人工验证

- 目录可以加载，筛选下拉、重置、搜索清除和多关键词搜索可操作。
- 分类聚合、父级全选/半选、全选当前结果和跳过已下载的选择逻辑可用。
- 侧栏收起、标题和分类的截断悬停提示可用。
- 应用内登录、登录后自动关闭窗口、退出登录均可用。
- 未登录下载即时提示；登录后单项下载显示解析、百分比传输、校验和完成状态。
- 下载文件通过 PDF 文件头与大小校验，输出目录和命名符合当前规则。

## 每次修改下载逻辑后至少验证

1. 清除应用登录档案后下载，确认界面立即提示登录。
2. 登录后下载一个小文件，确认进度、完成状态和文件校验。
3. 下载一个较大文件，确认进度持续刷新且界面保持可操作。
4. 中断下载，检查 `.part` 处理符合当前实现或任务设计。
5. 重新下载一个已下载资源，确认未被自动阻止。

## 批量队列与持久化（本轮新增）

1. 勾选多个资源点击“开始下载”，确认按顺序逐个下载、总进度与当前项标题、成功/失败/取消数量正确。
2. 下载过程中点击“暂停”，确认当前项变为已暂停、`.part` 保留；点击“继续”，确认从断点续传并完成校验。
3. 下载过程中点击“取消”，确认未完成任务变为已取消，相关 `.part` 文件被清理。
4. 制造失败项（如未登录或临时断网），确认任务页逐项显示原因，批次结束后可单独“重试”成功。
5. 下载进行中直接关闭应用再启动，确认任务恢复为“已暂停”且可继续，已下载项仍标记“已下载”。
6. 重新下载已下载资源，确认不会被自动阻止。
7. 任务页“清除记录”只清除队列记录，不删除已下载文件。
8. 快速执行“暂停”后立即“继续”，确认始终只有一个任务在下载，不会出现并发下载或最后一项“已下载”状态漏刷。
9. 缩小窗口后，确认单行教材名称用省略号截断，不侵入右侧列。

## 本地资料（本轮新增）

1. 下载若干文件后进入“本地资料”，确认按下载时间倒序列出教材名称、分类、大小和时间。
2. 搜索关键词与切换学科筛选，确认列表随之过滤且组合条件正确。
3. 点击“打开”能打开 PDF；点击“所在文件夹”能在资源管理器中定位该文件。
4. 手动把某个文件移到其他目录后点击“刷新”，确认该条目显示“文件已不在原位置”，且“打开”按钮禁用。

## 下载任务页增强（本轮新增）

1. 批量下载一批资源后，确认“当前批次”显示速度、已用时间、剩余时间和暂停项的断点进度。
2. 批次中存在失败项时，点击“重试失败项”，确认只重新入队失败/取消项，成功项不受影响。
3. 完成后开始新的下载批次，确认旧批次进入“历史批次”，且最多保留最近 5 个。
4. 展开历史批次可看到其中每项状态；“清空历史”只清历史，不影响当前批次。

## 安装包冒烟测试（本轮新增）

1. 运行 `smartedu-library-desktop/release/SmartEdu Textbook Library Setup 0.1.0.exe`，按向导完成安装并启动，确认窗口和教材目录正常。
2. 运行 `smartedu-library-desktop/release/SmartEdu Textbook Library 0.1.0.exe`，确认便携版无需安装即可启动。
3. 在打包版中重新登录平台，下载一个小文件，确认解析、进度、校验、完成状态和本地资料页均正常。
4. 确认打包版的数据目录与开发版 `.electron-data` 隔离，不会读取开发期的登录档案或下载记录。

## 自动化测试目标

- 目录字段标准化、分类键、多关键词匹配与选择状态的单元测试。
- 文件命名、PDF 头/大小校验和 `.part` 清理的单元测试。
- 队列状态机：入队、暂停、继续、取消、重试与重启恢复的单元测试。
- 基于脱敏 fixture 的 IPC 与下载状态集成测试。
- 发布前的 Windows 启动和安装包冒烟测试。

## 自动化测试（已实现）

- 运行 `npm test`（Vitest，25 项）。
- `tests/catalog-normalize.test.ts`：目录字段标准化与标题推断。
- `tests/catalog-logic.test.ts`：多关键词匹配、筛选收窄、分类聚合、选择与跳过已下载逻辑。
- `tests/download-utils.test.ts`：文件命名、路径布局、PDF 头与大小校验。
- `tests/queue.test.ts`：队列顺序执行、失败标记与批量重试、暂停/继续不并发、取消、重启恢复为暂停、孤立 `.part` 清理、批次历史归档。

测试数据不得包含真实 session、授权地址或教材文件。
